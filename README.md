### 기능 1: 자동차 이름 입력 및 유효성 검사 (10/21 ✅)
- 쉼표(,)로 구분하여 여러 대 입력 가능
- 각 이름은 5자 이하만 허용
- 잘못된 입력 시 `IllegalArgumentException` 발생

### 기능 2: 이동 횟수 입력 (10/21 ✅)
- 사용자로부터 이동 시도 횟수 입력
- 1회 이상 입력해야 하며, 잘못된 입력 시 예외 발생

### 기능 3: 전진 조건
- 0~9 사이 난수 생성
- 난수 >= 4 → 자동차 전진
- 난수 < 4 → 자동차 멈춤

### 기능 4: 라운드별 진행 결과 출력
- 각 라운드마다 자동차 위치를 `-`로 표시
- 자동차 이름과 함께 출력

### 기능 5: 최종 우승자 출력
- 가장 많이 전진한 자동차가 우승
- 공동 우승 시 쉼표(,)로 구분
